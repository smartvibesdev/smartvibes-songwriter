# Architecture Decision Records (ADRs)

Each ADR records one significant technical decision: the context, the options
considered, what was chosen, and the consequences. Files are numbered in the
order decisions were made and are not deleted; a reversed decision gets a new
ADR that supersedes the old one.

Format: [0000-template.md](0000-template.md)
