# 0002. License the project under MIT

- Status: Accepted
- Date: 2026-09-29

## Context

The repository is public and intended as a portfolio piece. The project plan
suggests MIT as the default.

## Options considered

- MIT: permissive, short, widely understood by employers and contributors.
- Apache 2.0: permissive with an explicit patent grant; longer.
- No license: all rights reserved, so nobody can legally reuse the code.

## Decision

MIT, as already reflected in the `LICENSE` file.

## Consequences

Anyone may use, modify, and redistribute the code, including commercially,
provided the copyright notice is retained. No warranty is offered.
